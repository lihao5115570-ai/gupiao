# 其他电脑安装说明

推荐方式：代码用私有 Git 仓库同步，真实持仓、数据库、接口密钥留在每台电脑本地单独配置。

## 为什么不要直接复制全部文件

`data/stock_monitor.db` 里包含持仓、通知设置、接口密钥、提醒记录和回测数据。它适合本机保存，不适合上传到 Git，也不适合发给别人。

## 方式一：私有 Git，同步代码

适合以后我继续帮你升级软件。

1. 在 GitHub、Gitee 或 GitCode 新建一个“私有仓库”。
2. 只上传 `stock_monitor_assistant` 目录里的代码文件。
3. 不要上传 `data/`、`screenshots/`、`.env`、任何 `*.db` 文件。
4. 另一台电脑安装 Python 3.12 或更高版本。
5. 从私有仓库下载代码。
6. 在新电脑进入项目目录，安装依赖：

```powershell
python -m pip install -r requirements.txt
```

7. 双击 `启动股票持仓监控助手.cmd` 启动。
8. 第一次启动后，在软件里重新填写：
   - 持仓
   - Infoway 行情接口 Key
   - 通知设置
   - 9:25 竞价参数

## 方式二：压缩包复制，最快

适合先在另一台电脑临时使用。

1. 复制整个 `stock_monitor_assistant` 文件夹。
2. 删除复制件里的 `data/` 和 `screenshots/`。
3. 把剩下的文件压缩成 zip。
4. 在另一台电脑解压。
5. 安装 Python 后双击 `启动股票持仓监控助手.cmd`。
6. 重新配置持仓和接口 Key。

## 是否要同步数据库

一般不建议同步数据库。

如果你只是自己两台电脑都用，且确定两台电脑不会同时运行，可以手动复制 `data/stock_monitor.db`。复制前先关闭软件，复制后再打开。这样会连同持仓、参数、提醒记录一起带过去。

如果两台电脑会同时开，不要共用同一个数据库，否则提醒记录、回测样本和持仓状态容易混乱。

## 最推荐的实际用法

主力电脑：负责每天 9:18 前启动、采集竞价、持仓监控。

备用电脑：只同步代码，必要时手动重新填 Key 和持仓。

手机查看：继续用 Tailscale 打开主力电脑的网页，不需要把软件装到手机上。
