# 股票持仓监控助手（Windows 10 本地版）

这是一个只做持仓监控、技术分析、风险分级和 Windows 提醒的本地软件。它不会登录交易账户，不读取交易密码，不点击同花顺买卖按钮，也不会执行任何自动交易。

## 直接运行

双击 `启动股票持仓监控助手.cmd`。

首次打开后点击“添加持仓”，填写股票代码、名称、成本、日期和数量，再点击“开始监控”。关闭主窗口时软件会隐藏到系统托盘并继续运行；双击托盘图标可恢复，右键可退出。

## 已实现

- 多持仓统一监控，列表按风险等级自动排序
- 东方财富公开行情接口：实时价格、日K、60分钟K、15分钟K
- 本地计算 BOLL、MACD、KDJ、VOL、支撑位和压力位
- 成本收益、买入后最高价格、最高浮盈和高点回撤
- 1至5级联合风险判断与利润保护规则
- 重要事件触发 Windows 右下角通知，普通波动不反复提醒
- SQLite 保存 `stocks`、`positions`、`price_data`、`indicators`、`signals`、`alerts`、`settings`
- 原生系统托盘、当前用户开机启动、交易时段与非交易时段分频
- 读取当前可见同花顺窗口标题并保存辅助截图

## 数据与提示边界

默认行情来自第三方公开接口，可能存在延迟、停牌缺失、接口调整或网络不可用。风险等级是基于技术指标的观察工具，不构成投资建议。重要决策请以券商/交易所数据和自己的交易计划为准。

同花顺辅助功能目前读取可见窗口的标题与截图，不做 OCR，也不作为后台行情主数据源。窗口最小化时仍可继续独立监控行情。

## 文件位置

- 数据库：`data/stock_monitor.db`
- 同花顺截图：`screenshots/ths_current.png`
- 启动入口：`main.py`
- 自动测试：双击 `运行诊断测试.cmd`

核心功能只依赖 Python 标准库；同花顺截图使用电脑上已安装的 Pillow。建议使用本机 Python 3.12 或更高版本。
# 9:25竞价候选

程序包含独立的“9:25竞价候选”标签页，不与持仓分析混用。保持程序在交易日上午运行后，它会在9:15-9:25保存全市场竞价路径，在9:25锁定第一份成功数据并生成“可挂入 / 等回踩 / 放弃”三档结果。9:25:40以后拒绝用盘中或盘后数据补写竞价快照，9:30以后只保留结果供查看。

默认硬门槛：锁单留存率不低于70%，最高涨幅回撤不超过2个百分点，9:24:30后下降不超过0.5个百分点，竞价额不低于2000万元；创业板、科创板、北交所、ST/退市整理和100元以上股票默认关闭。门槛可在竞价页调整。

保守模式还会检查全市场覆盖率、跨页采样时差和采样启动延迟；任一正式采样点质量失败，当天所有股票都不能进入“可挂入”。A档要求留存率不低于90%、路径回撤不超过0.8个百分点、末段下降不超过0.15个百分点、锁单涨幅处于1%-5.5%、板块至少5只正竞价，并同时满足绝对和相对竞价额。每天最多3只，每个板块最多1只。

程序会在9:30、9:35、10:00和15:00记录候选后续表现，只用于统计近30日9:35上涨率、收盘上涨率和盘中触及+1%的比例，不会修改已经锁定的9:25结论。

A档候选还必须通过腾讯行情的独立价格与时间戳校验。第二行情源缺失、时间戳陈旧，或两源价格/涨幅超出容差时，该股票直接降为“放弃”。开盘后验证使用快速候选报价，并以9:30价格不高于建议限价作为“模拟可成交”条件；后续涨跌以模拟成交价为基准，不再假设能成交在9:25锁单价。模拟成交少于50只时不展示胜率，避免小样本误导。

“成交概率”和“建议挂单价”是基于公开行情的规则估计，不含交易所逐笔委托队列，也不保证成交。软件不会连接交易账户或自动下单。

## 独立历史回测审核

- 当前参数名为“保守试验版”，不是已通过历史验证的最终参数。
- 正式回测只接受每个必需采样点均为 `live/passed` 的真实9:25路径，并要求15:00真实收盘记录完整。旧数据、盘后补算、模拟或来源不明数据不进入正式胜率。
- 竞价成本使用9:25实际锁单价；当日9:30-15:00最低价、最高价和收盘价用于计算不破成本率、收盘胜率和最大不利波动 `MAE`。
- 同一交易日、同一股票只记一个独立信号，同源生成的多张表不重复计数。
- 每套阈值会生成独立版本指纹。修改任一阈值后是新试验，不能把旧数据倒算成新版本的样本，防止样本外泄漏。
- 正式资格要求：至少30个交易日、50个独立信号，且最近10个交易日样本外也必须达到不破成本率≥80%、收盘胜率≥70%、平均MAE≤0.50%、MAE>2%比例≤5%。
- 未达标时只输出“试验观察”、“等待9:35确认”或“放弃”；达标且通过最近10日样本外审核后，才允许显示“竞价小仓”。

## 候选三区间与同花顺自选

- 在“9:25竞价候选”选中一只股票，点击“计算三个区间”，程序会根据日K结构计算支撑区、博弈区和压力区。
- 没有选中时，默认处理当前所有“可挂入/等回踩”候选，不处理“放弃”股票。
- 点击“加入同花顺自选”前，请把同花顺停在普通行情或K线页面。程序只会输入股票代码、回车和 `Insert`，不会打开交易界面。
- 检测到委托、下单、买入或卖出窗口时，同步会立即拒绝执行。
- 同花顺原生画线文件有版本和完整性校验，程序不直接改写这些文件，避免损坏已有画线。
